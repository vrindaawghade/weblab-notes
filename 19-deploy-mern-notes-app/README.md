# Experiment 19: Deploy MERN Notes App

**Question:** Deploy a MERN notes application using a suitable cloud platform. Configure the frontend and backend URLs, connect the database, and verify that adding and viewing notes works after deployment.

**Requirements:** Node.js + MongoDB (local or Atlas)

## How to run
1. Start MongoDB (or put an Atlas URI in `.env` - copy `.env.example`).
2. `npm install`
3. `npm start`
4. Open http://localhost:5000

Deployment steps: see `DEPLOYMENT.md`.
